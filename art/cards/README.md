# Card drawings (Damien)

Drop drawings here and they appear on the cards in the game.

- **Size:** 512 × 512 pixels, PNG
- **Background:** transparent
- **Name:** exactly the card's name, e.g. `Pig.png`, `Spool of Thread.png`, `Cowboy Hat.png`
- Draw only the object; the game draws the card (paper, colour band, name) around it.

The full list of names is in `new-game-plan/10-art-checklist.pdf`.
